    02 / ENGINEERING BLUEPRINT

    Una arquitectura hecha
    para el día difícil.

    El backend original funciona con dos bases PostgreSQL separadas en un entorno local y de CI: una almacena trabajos; la otra evita repetir efectos del receptor.

    01

    Ingress autenticado

    HMAC-SHA256 sobre bytes crudos, comparación constante, límite temporal y payload validado.

    Fastify · raw body
    02

    Persistencia atómica

    Inbox y job nacen juntos. El servidor emite 202 solo después del commit.

    PostgreSQL · unique key
    03

    Worker reclamable

    Un lease con fencing token evita que un worker viejo confirme una tarea recuperada.

    SKIP LOCKED · leases
    04

    Efecto idempotente

    El receptor guarda un recibo durable por identidad estable, aunque reciba HTTP dos veces.

    receiver_db · delivery_id
